# Hardware testing and documentation status

The project owner performs functional testing on the FM-1. The owner reaffirmed this on 2026-11-15. Public player instructions and release notes should not describe the firmware as untested simply because the coding agent did not operate the hardware.

Earlier reports are snapshots of development work, not a current verdict on whether the game is tested. This update audits those statements and distinguishes owner-performed functional testing from instrumented measurements. Where a report marks timing, stack peaks, headroom or revision coverage UNVERIFIED, that means the specific measurement or coverage record is not documented; it does not mean the firmware has never been played on hardware. Do not invent numeric measurements or both-revision coverage from a general functional-testing report.

Owner-reported installation/training/exit tests are retained as reports. Future exact hardware measurements and detailed device reports belong here or in the relevant engineering report, rather than repeated warnings in the README, installer or release description.

Audit scope: project README, project-authored docs, landing page, generated installer banner, recovery README generator and both published GitHub release descriptions. Retained upstream source/licence documentation is not rewritten as project hardware evidence.
